Nova automação

Comentário com palavra-chave → resposta no comentário → 1ª DM com botão → link após o clique.
Maiúsculas e acentos são ignorados. "Contém" exige a palavra inteira: ebook casa com "quero o EBOOK!", mas não com "ebooks".
"Qualquer post": os 50 posts mais recentes são verificados a cada 20s; posts mais antigos disparam na hora quando a Meta envia o evento por webhook.
Cada comentário recebe uma resposta sorteada, sem repetir as últimas usadas.
O link só é enviado depois que a pessoa toca no botão. O botão aparece no app do Instagram para celular.
